# DSA Visualizer & Concept Studio 🚀

A modern, interactive Data Structures & Algorithms learning platform and step-by-step visualizer built with React, TypeScript, and Tailwind CSS.

---

## ✨ Features

- **Tilted Glassmorphism Landing Page**: Interactive cursor-tracking spotlight border effects over DSA pattern badges.
- **8 Comprehensive Syllabus Modules**: From Big-O complexity analysis and two-pointer array patterns to recursion, binary search trees, and dynamic programming basics.
- **Light & Dark Mode**: Seamless theme switching with high-contrast, distraction-free reading typography.
- **Interactive Step Engine**:
  - Play, Pause, Step Next, Step Previous, and Reset controls.
  - Speed multiplier adjustments (0.5x to 2x).
  - Dynamic custom input arrays and target search values.
  - Real-time pointer badges (`left`, `right`, `mid`, `start`, `end`) and step explanation log.
- **Downloadable Notes**:
  - Export topic notes as clean offline Markdown (`.md`).
  - Formatted Print & Save as PDF study sheets.
- **Multi-Language Implementation Tabs**: Code snippets with 1-click copy for JavaScript, Python 3, C++, and Java.
- **Smooth Interaction**: Powered by Lenis smooth scrolling.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Icons**: Lucide React
- **Smooth Scrolling**: Lenis
- **Delight Effects**: Canvas Confetti
